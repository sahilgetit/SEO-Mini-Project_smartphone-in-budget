# SEO Mini Project – Budget Smartphones Niche

An end-to-end SEO project covering everything from niche validation to a live, optimized WordPress website. This project was built to demonstrate a practical, hands-on understanding of how real-world SEO campaigns and websites are planned, built, and deployed.

## 📌 Project Overview

The goal was to identify a profitable, high-demand niche, validate it through keyword research, and build a fully functional, SEO-optimized website around it — covering domain selection, hosting, server setup, and WordPress configuration.

**Niche:** Budget Smartphones (India)

## 🔍 What This Project Covers

- **Niche Selection & Justification** — Identified budget smartphones (sub-₹20,000 segment) as a high-demand, moderately competitive niche with strong long-tail keyword potential and affiliate monetization opportunities (Amazon, Flipkart, Croma).
- **Keyword Research** — Used Ubersuggest to extract and analyze keyword volume, difficulty, and search intent.
- **Keyword Selection** — Chose primary and secondary keywords based on search volume and transactional intent (e.g., "best phones under 15000", "best 5G phones under 15000").
- **Longtail & LSI Keywords** — Expanded keyword targeting for broader content coverage and semantic relevance.
- **Domain Research & Selection** — Evaluated multiple brandable domain options and finalized on a short, niche-accurate domain.
- **Domain Registration**
- **VPS Setup** — Provisioned and configured a virtual private server for hosting.
- **Cloudflare Setup** — Configured DNS, SSL, and performance/security settings.
- **WordPress Installation & Customization** — Set up themes, plugins, and on-page SEO structure.
- **Backup Configuration**
- **Final Website Screenshots**

## 🛠️ Skills & Tools Used

- Keyword Research: Ubersuggest
- Hosting & Infrastructure: VPS, Cloudflare (DNS/SSL)
- CMS: WordPress (themes, plugins, on-page SEO)
- Domain Registration & Management

## 💡 Key Learnings

This project provided hands-on experience across the full SEO and website deployment pipeline — from validating a profitable niche and conducting structured keyword research, to handling technical infrastructure like DNS, SSL, and server security, to optimizing a WordPress site for search performance. It strengthened both analytical skills (niche/keyword evaluation) and technical skills (VPS, Cloudflare, WordPress), building confidence to independently manage and scale SEO-focused websites.
